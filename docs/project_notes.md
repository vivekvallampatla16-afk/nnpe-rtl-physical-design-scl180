# Project Notes

This repository is a cleaned portfolio version of the NNPE project. It includes only safe public material:

- synthesizable RTL and a directed testbench
- architecture and physical-design screenshots
- summarized QoR, congestion, timing, and routing-check reports
- no foundry PDK files, standard-cell libraries, `.db`, `.lib`, `.lef`, `.tf`, `.tluplus`, `.ndm`, GDS/OASIS, SPEF, SDF, or tool databases

The original internal/report files included tool paths and license messages, so they were converted into sanitized markdown summaries before GitHub upload.
